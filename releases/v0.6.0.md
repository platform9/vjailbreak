# v0.6.0

- **Tag:** `v0.6.0`
- **Published:** 2026-10-29T09:57:13Z
- **Source release:** https://github.com/platform9/vjailbreak/releases/tag/v0.6.0

## Release Notes

## Highlights
- vJailbreak Accelerated Copy now supports a configurable NBD port range, set from the UI
- Faster VMware initial discovery and credential revalidation
- Network configuration for the auto-deployed vJailbreak Accelerated Copy proxy VM can now be set from the vJailbreak UI

## Bug Fixes
- Added validation and remediation for VMs that have CBT enabled at the VM level in vCenter but not at the disk level
- Fixed scaling and migration failures in environments where the vJailbreak VM's guest hostname does not match its OpenStack instance name
- Fixed vCenter session timeouts causing vJailbreak Accelerated Copy to fail during attach/detach operations
- Fixed OOMKilled failures during disk copy and conversion

## Known Limitations
- RDM migrations are not supported with vJailbreak Accelerated Copy. Standard Copy still supports RDM.
- The vJailbreak worker agent "Reprovision" action has a known race condition. We recommend deleting the agents explicitly and creating new ones if needed.
- Retrying a failed migration switches its storage copy method to vJailbreak Accelerated Copy. Delete the failed migration and start a new one instead of retrying.
- Migrations using vJailbreak Accelerated Copy may fail during conversion due to a race condition when multiple migrations run in parallel. This happens regardless of the guest OS configuration.

## Notes
- vJailbreak sizes the libguestfs appliance memory automatically. Do not set `LIBGUESTFS_MEMSIZE` in the `pf9-env` ConfigMap; doing so may cause migration failures.
