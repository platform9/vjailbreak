---
title:  v0.5.0
description: Release Notes for v0.5.0
---

* **Accelerated Copy improvements**

  * Added support for **hot migrations** with vJailbreak Accelerated Copy.
  * Fixed a race condition during volume attachment on the proxy VM.
  * Fixed PVSCSI affinity handling for Accelerated Copy.
  * Added automatic PVSCSI controller creation during onboarding instead of failing verification.

* **Migration reliability and safety**

  * Added checks for VM power state before forcing a power-off after a graceful guest shutdown attempt.
  * Added guardrails for boot partition detection.
  * Added automatic detection and reporting of insufficient root partition capacity.
  * VMwareCreds deletion is now blocked when a migration using those credentials is in progress.
  * Improved handling of Virtual IP addresses when migrating to PCD networks.

* **Storage and platform support**

  * Added **Hitachi storage support** for storage-accelerated migration through Cinder-mediated LUN mapping.
  * Added support for authenticated HTTP(S) proxies.

* **Upgrade and resource management**

  * Improved resource management during the in-place upgrade flow.
  * Reduced the number of Guestfish calls performed per migration.

* **OpenStack and agent improvements**

  * OpenStack VMs created for Agent nodes now use the primary vJailbreak name as a prefix.
  * Fixed incorrect handling of flavors associated with Nova host aggregates.

* **Operations and observability**

  * Made sync-daemon log retention configurable.
